# Foodie

Bradley Beachoo

A React Native recipe app with categories, recipe details and favorites. My Food lets you add recipes with photos, edit them and delete them.

To review it, open Snack and choose **Import Git Repository**. Paste the GitHub link above, use **SDK 54**, and select **Web**.
